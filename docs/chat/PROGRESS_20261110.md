# EX chat 开发进度与后续计划

存档日期：2026-11-10。分支：chat。状态：文字服务骨架已实现，真实 AstrBot 内置指令与重连闭环通过，第三方插件兼容仍待验收。

## 已完成

- ChatService / SQLite：统一真人和 bot 账号、成员权限、私聊/群聊、文字发送、UUID 幂等、历史、撤回、持久事件和账号绑定游标。
- 原生 HTTP/WS 和内置 OneBot11 反向 Universal WS；EX 宿主按需管理生命周期，聊天独立开发入口可用。
- 新增 scripts/chat_astrbot_lab.py：使用预装镜像完整 ID，临时 AstrBot 数据与协议 token，仅 loopback 发布机器人端口；验证结束移除临时容器和数据。
- 真实 AstrBot 4.26.7 的原生 aiocqhttp 适配器及未修改 builtin_commands /sid 已完成双真人群聊、bot 私聊、身份核对、访问隔离和机器人容器重启后的重连；还单独跑过 astrC 的真实 Dart HTTP 客户端。
- 手动服务模式使用独立持久测试目录、普通原生 API 和首次生成的随机测试密码；支持指定本机 LAN 地址供 APK 联调。没有对外开放 --demo。
- compatibility-matrix.json 已加入限定到 /sid 的内置插件证据。机器证据见 acceptance/20261110/real-astrbot-roundtrip.json，固定镜像和关键源文件 SHA-256。

## 本轮验证与发现

原有聊天/API/interaction 35 项 pytest 和 11 个 subtest 通过。真实 HTTP 场景、真实 Flutter 客户端和正常模式 LAN 启动自检通过。Android 真机由用户后续手测，本轮未作安装验收。

重连测试最初失败，定位为 Docker 在 restart 后重新分配随机 host port；固定测试 host port 后通过。该修正属于测试环境，不将其描述成 EX 传输缺陷。测试只证明本次重连后新消息成功返回，不承诺断线窗口内端到端恰好一次。

本机 AstrBot-latest HEAD 与固定镜像并非同一版本；不把本轮结果推广到未测试版本、第三方插件或 QQ/NapCat 对照。生产 Docker 容器与配置未改动。本轮没有修改 ChatService / API / 消息段契约。
