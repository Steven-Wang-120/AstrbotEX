# EX chat 开发进度与后续计划

存档日期：2026-11-10。分支 chat。文字、@ 与引用已贯通原生 API、OneBot11 与真实 AstrBot；Android 真机和第三方插件仍待验收。

## 本轮完成

- 支持 native text/mention/reply 严格模型和事务校验，OneBot text/at/reply 显式双向映射、CQ 文本转义。
- 提及目标限定群成员，all 限群主/管理员；引用必须是同会话未撤回消息，至多一个且位于首段，正文合计最多 4000 码点、最多 16 段。
- 相同幂等请求在引用目标撤回后仍返回原消息；新消息拒绝跨会话/不可见/撤回引用，校验失败不落消息或事件。
- get_msg 返回完整上下文，get_stranger_info 限本人及共享会话成员，满足真实 AstrBot 提及和引用解析。
- 隔离 AstrBot 4.26.7 开启回复提及和引用，未修改其适配器或内置指令源码；实际 Dart HTTP 客户端亦通过。
- 权威契约 revision 2026-11-10.3，Schema 限定当前三种段，附组合示例，实际 OpenAPI 重新生成。EX 提交后同步 astrC 快照。

## 验证

57 项 pytest、11 个 subtest 通过，涵盖原有聊天/API/interaction 与新增段消息权限、幂等、错误形状、无副作用失败。真实 AstrBot 七个场景通过：双真人群聊、私聊、提及加引用、重启重连、私聊隔离及真实 Dart 客户端。

证据：[提及与引用联测](acceptance/20261110/segments-astrbot-roundtrip.json)。内含固定镜像 ID、关键源码 SHA-256 与实际适配器查询结果。早期文字联测及 Windows PowerShell 5.1 普通模式持久测试库重启证据仍保留。生产容器与配置未改动。
