# EX chat 图片阶段进度

日期：2026-11-11。真人静态图片可上传、入消息、按会话鉴权下载；OneBot 图片尚未接入，继续明确返回不支持发送。

## 已完成

- native image 段，POST /media 原始二进制上传，conversation_id 与 client_media_id query 参数；GET /media/{id} Bearer 读取。
- 静态 PNG/JPEG/WebP，输入/规范化各不超过 8 MiB，单边 8192、总像素 1600 万；拒绝动图、SVG、损坏数据，应用 EXIF 方向并重新编码清除元数据。
- 图片 BLOB 与配额进入 SQLite；migration 1→2，消息/引用关系/事件同事务。每账号 64 MiB，未发送上传也计入，过期清理尚未实现。
- 上传者可读未发送图片；其他成员须有未撤回消息引用，最后一条引用撤回后拒绝新下载。发送只允许本人为当前会话上传的 media_id，跨会话和盗用他人附件拒绝。
- 图片上传 UUID 和消息 UUID 分别幂等，重复上传不占重复配额。API 接收实际流量有上限，不能仅凭 Content-Length 绕过。
- OneBot 对真人图片显示 [Image] 占位，can_send_image=false；没有签名图片 URL、远程抓取或本机路径读取。
- 契约 revision 2026-11-11.1，Schema、实际 OpenAPI、图片示例更新。Pillow 13.0.0 固定到 chat 可选依赖，chat Python 需 3.11+，当前实际 3.12.10。

## 验证

72 项 pytest、11 个 subtest 通过，覆盖原有文字/@/引用、图片格式与尺寸/字节限制、元数据/方向、权限、幂等、撤回、配额、数据库迁移与重启。

真实 AstrBot 共存联测八个记录场景通过：图片原生权限与占位、双真人群聊、私聊、@/引用、重启重连、私聊隔离及实际 Dart 客户端。证据：[图片阶段联测](acceptance/20261111/native-image-astrbot-roundtrip.json)。镜像与适配器/内置 /sid 源码保持不变；不将其解释为机器人图片或第三方插件兼容。
