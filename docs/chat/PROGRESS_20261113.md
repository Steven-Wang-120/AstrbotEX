# 媒体聊天升级

功能实施于 2026-11-13，交付整理于 2026-11-14。仅修改 EX `chat` 分支，协议修订 `2026-11-13.1`；配套 astrC 为 0.3.0+6。

已实现图片、文件、静态/动态表情、Emoji 以及持久表情收藏。手机和 EX 管理页均使用 ＋ 附件面板、笑脸面板、图标和必要短标签，每条消息显示发送时间。教程放文档，页面不放常驻使用指导。

附件在签名加密正文内传输，最多 4 个、原始字节合计 8 MiB；保留旧纯文字正文。邮箱只保存密文，单次 inbox 返回量及全节点未 ACK 容量有界。EX 以 SQLite BLOB 保存附件，数据库自动迁移至 user_version=3，收藏按数量和容量限额。管理接口沿用认证；Agent 附件 URL 绑定访问账号、可见消息和到期时间。

证据：[双节点媒体](acceptance/20261113/peer-media-roundtrip.json)、[真实 AstrBot 媒体](acceptance/20261113/real-astrbot-media.json)。PNG、二进制文件、GIF 的回传摘要与原字节一致；发送时间、固定 outbox、重启、ACK 去重和收藏恢复均有场景覆盖。

真实探针从原始 OneBot 事件取签名 URL；普通 AstrBot 图片预处理可能转码。Agent 发媒体目前仅接受有界 base64://，普通 file:// 文件插件仍需适配。未验收第三方插件、QQ/NapCat 对照、实体 Android、iOS 和后台推送。

上线时需同时升级邮箱单文件和 EX 镜像，配置 Agent 可达的 `ASTREX_CHAT_MEDIA_BASE_URL`；当前容器网络可用 `http://astrbotex:8780`。升级前应停止 EX 后备份完整数据，再切镜像。回退旧 EX 代码须同时恢复升级前完整数据库；保留升级后数据副本，不能让旧版打开 v3 库。没有更换身份或清空聊天的步骤。

本轮不将部署准备当作已上线；公网节点当前仍是旧版，媒体需待节点与 EX 升级后使用。旧版文字链路及历史部署证据保留。
