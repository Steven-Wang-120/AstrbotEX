# Mobile manipulation in Isaac

This plugin declares move and fetch through the common task contracts. It starts disabled. Loading it does not start a robot scene or submit a command.

`configure_execution(profile_hash, regions, profile=..., compile_fetch=..., physical_evaluator=..., observation_provider=...)` is a trusted in-process interface. Configure it before formal Goal submission. The region table maps `table_dock/home` to [x,y,yaw] or a ROS target_pose. The profile hash must match the R gateway.

`compile_fetch(params, observation, profile)` returns a bounded list of `{name, op, payload, settle_sim_seconds?}` stages. The common R gateway plans each arm stage and applies its Guard. No external joint trajectory can enter this plugin. Optional settle_sim_seconds must be within 0..2. The plugin waits for observation.source_stamp to advance by that simulation duration after a successful stopped stage. It continues cancel handling and rejects stale or stalled observations. The observation provider supplies received_monotonic for explicit age checking.

`physical_evaluator(command, stage_results, observation)` returns `{physical_complete, success, evidence_reference, details}`. It can return physical_complete=false while it waits for the required stable window. The worker polls until completion or the macro lease expires. Without a recipe, evaluator or observation provider, fetch remains unavailable. Move also requires independent arrival-and-stop evaluation.

Action callbacks only admit or cancel. One bounded pure callback worker handles recipe and physical evaluation; it cannot publish ROS. Late results are discarded after cancellation. The Actor worker reads declared ROS inboxes and publishes command, lease and cancel messages. It does not create rclpy nodes or executors. Ordinary cancel uses normal publication. Only environment deactivation uses the authorized publish_stop hook.

One EX macro command maps to `parent_command_id/0`, `/1`, and subsequent R stages. Every stage uses the same EX session/Goal revision and a newer execution epoch. Stage results must match all identity fields. Cancel stops lease renewal and invalidates later stages.

A gateway result has controller_stage scope and physical_complete=false. It cannot complete the macro action. The plugin reports success only after independent physical evidence. It maps a trusted stage stop proof to the parent command and preserves the original stage ID and evidence reference. Missing proof retains the active action and resources.

The final Isaac gate and gateway watchdog operate independently of this plugin. A failed ROS publication is not a received stop. First-stage communication unit tests are not physical execution evidence.

`plugin.json` is generated by `generate_manifest.py` from `core.tasks.contracts.action_manifest()`. Do not hand-edit a second action schema.
